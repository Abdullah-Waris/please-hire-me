# Historical archive

These files explain where the project came from. They are **not current setup instructions, trusted facts, or executable worker policy**.

- `historical-browser-recipes.md`: v0.2 browser workflow and observations. Its claims and personal assumptions are historical and unverified.
- `code-broker.py.txt`: disabled legacy Gmail/clipboard broker placeholder. Current optional Gmail handling is in `hireme/gmail.py`.
- `resume-server.py.txt`: disabled localhost PDF transport placeholder. Current uploads use private, hash-checked documents.
- `block-secret-read.sh.txt`: retired regex hook. Current model capability restrictions are implemented by provider adapters.

Historical command names inside these files intentionally describe the old layout. Use the [current README](../../README.md) and [worker contract](../worker-contract.md) for operations.
