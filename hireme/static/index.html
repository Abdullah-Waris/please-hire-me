Connect the same email you use on applications to read verification codes and receive batch reports. Being signed into Gmail in a browser does not grant background access.

Create a Desktop app OAuth client with the Gmail API enabled in your Google Cloud project. The credentials stay in private storage. Google setup instructions.

Then run this from the project folder in a terminal on the computer running the worker: 

.venv/bin/python -m hireme gmail connect

Google will open a consent screen. Select your confirmed application email and authorize reading email and sending reports. Testing-mode OAuth tokens generally expire after seven days; finish the personal-use OAuth setup before relying on unattended runs.
